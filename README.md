## Фигуры + карандаши

# Описание:

Эта программа позволяет нарисовать на холсе фигуры и изменить их цвет. Приложение реализует паттерн "Компоновщик". (круг, треугольник, квадрат)

# Установка и запуск:

Клонирование репозитория:

<git clone Maryssika/Task2>

# Основные компоненты:

- Фигуры для рисования

- Рабочее окно

- Controller
